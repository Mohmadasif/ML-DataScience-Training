# Module 3 – Supervised Machine Learning

Welcome to Module 3 – Supervised Machine Learning.

This module focuses on the fundamental supervised learning algorithms used for regression and classification, along with model evaluation, validation, and hyperparameter tuning.

## 📚 Topics Covered

### 1. Linear & Logistic Regression
- Linear Regression
- Multiple Linear Regression
- Logistic Regression
- Regression vs Classification
- Model prediction and interpretation

### 2. Decision Trees & Random Forests
- Decision Tree fundamentals
- Splitting criteria
- Gini Impurity
- Entropy
- Random Forest
- Bagging and ensemble learning
- Feature importance

### 3. Support Vector Machines (SVM)
- Introduction to SVM
- Hyperplanes and decision boundaries
- Margins
- Support vectors
- Linear and non-linear classification
- Kernel functions

### 4. K-Nearest Neighbours (KNN)
- How KNN works
- Distance-based classification
- Choosing the value of K
- Feature scaling
- Advantages and limitations of KNN

### 5. Gradient Boosting
- Introduction to boosting
- Gradient Boosting
- XGBoost
- LightGBM
- Ensemble learning concepts
- Model comparison

### Regression Metrics

## ⚙️ Hyperparameter Tuning

- Parameters vs Hyperparameters

- Comparing model performance
